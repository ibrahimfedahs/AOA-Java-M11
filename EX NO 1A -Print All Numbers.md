
# EX 1A Print All Numbers 
## DATE:
## AIM:
To Write a Java program that takes an integer input N from the user and prints all the numbers from 1 to N, separated by spaces, on a single line..

## Algorithm
1. Start
2. Read a string from the user.
3. Initialize an empty string reverse.
4. Traverse the string from the last character to the first character and add each character to reverse.
5. Print the reversed string and Stop.
